# Open collaboration protocol

Open collaboration permits selected prior contributions to influence downstream work. That influence must be visible in `depends_on`; it must never be mislabeled as an independent review.

Recommended roles are producer, methods critic, evidence critic, implementation verifier, and adjudicator. Roles are contracts, not model brands. A low-cost model can fill a bounded lane when its output is independently checked.

The hub owns scheduling and context selection. Spokes cannot directly edit another spoke's event, advance state, or mark their own output accepted.

Manual shared/private turns can record attributable work, but blind or mixed interaction requires a roundtable plan so the roster and barrier are machine-enforced. Roundtable findings receive node namespaces; manually appended findings must already be unique across the project.

Provider retries cover provider-call failures only. Invalid governed output is recorded without paying for another model call, and a ledger commit error propagates rather than re-invoking a provider after an ambiguous write.
