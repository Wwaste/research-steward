# Blindness contract

A blind node may depend on the frozen packet and non-review production artifacts, but not on a sibling review node. The roundtable scheduler enforces this structurally. Blind review is not available through manual append tools.

The governed barrier becomes complete only after every rostered blind peer has a terminal event; a failed peer produces a blocked barrier. A downstream node may read that group only by depending on every member. If a reviewer prompt includes peer content, a mutable file is used instead of the frozen copy, or a report is modified after commit, the independence claim is invalid and requires a new run ID.
