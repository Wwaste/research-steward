# Failure semantics

Missing provider, authentication failure, timeout, invalid schema, hash mismatch, path escape, budget exhaustion, and blocked authority are explicit events. The coordinator must not substitute an uncalled model, fabricate a successful result, or silently downgrade a blind run to open collaboration.

An unresolved private blocker remains hidden from shared event listings, but project status exposes its minimal routing identity so the shared workflow cannot silently appear clear. A provisional review is attention-required state, not failure recovery, acceptance, or packaging authority.
